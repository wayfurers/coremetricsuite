# Core Metric Suite 📊

A collection of 12 micro-niche web utilities for tax, legal, and media safe zones.

🌐 **Live Tool Suite:** https://coremetricsuite.com

## 🔒 Privacy-First Architecture
* **100% Client-Side Sandbox:** Calculations execute entirely inside your local browser.
* **Zero Server Logging:** No data footprints or personal calculation tracking.
* **Ad-Free Structure:** Fully ad-free configuration optimized for maximum processing speed.

## 🧮 Available Utilities
* **AU Tax/Labour:** Cents-Per-Km Tax Estimator & SCHADS Award Allowance engine.
* **US Tax:** Section 179 Vehicle Deduction Engine & LLC Late Penalty Estimator.
* **UK Legal:** Form 4A Rent Tracker & Section 8 Eviction Calculator.
* **E-Commerce & Layout:** Shopify Metafields Parser, Instagram Reels, YouTube Shorts, & TikTok Ad Safe Zone UI Previewers.
